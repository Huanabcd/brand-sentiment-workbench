# 安装与更新

## 首次安装

1. 在 Releases 中下载与你电脑匹配的完整安装包，并核对同一版本提供的 SHA-256。
2. 完整解压 ZIP；不要直接在压缩包内运行。
3. macOS Apple Silicon 双击“启动试用版.command”；Windows 10/11 x64 双击“启动试用版.cmd”。
4. 软件只在当前电脑的 `127.0.0.1` 本机地址运行。保持启动窗口开启，关闭窗口即停止软件。
5. 无许可证的新安装会在授权页面显示安装标识。取得与该安装标识匹配的试用或正式许可证后，在页面中换入许可证文件。

当前技术验收包尚未进行 Apple 公证或 Windows 代码签名，系统可能显示安全提醒。正式对外版本发布前会另行完成系统签名与双平台真机验收。

计划发布的 [v0.24.0](https://github.com/Huanabcd/brand-sentiment-workbench/releases/tag/v0.24.0) 处于对外技术验收阶段，不是收费正式版。macOS Apple Silicon 将按 v0.23.0 → v0.24.0 完成真实在线更新验收并在发布后补充结果；Windows x64 仍只有静态完整性与架构验证，尚未完成真机验收。

`0.x` 版本仍属于对外测试阶段：补丁修复递增最后一位，新功能递增中间位，首个商业稳定版才使用 `v1.0.0`。由于客户端通过 `/releases/latest` 检查更新，这些技术验收版本会发布为普通 GitHub Release，而不是 Pre-release；普通 Release 仅用于保证更新链路可用，不表示已经成为收费正式版。

## 在线更新

1. 打开“品牌舆情工作台”。
2. 在首页或“品牌设置”中点击“检查更新”。
3. 有新版本时，依次确认“下载更新”和“安装并重启”。软件不会后台静默安装。
4. 下载完成后，客户端会先验证独立发布签名与文件哈希，再切换版本。新版本不能正常启动时会回到原版本。

程序更新不会替换本机品牌资料、导入内容、安装标识和许可证。为了便于更新，请把解压后的程序目录放在当前用户可写的位置，不要直接放入需要管理员权限的系统目录。

旧内部验收包（原编号 v1.2）不含稳定更新基座，不能直接在线升级；需要先手工下载并更换一次当前完整包，之后才能使用上述更新流程。

## 数据位置

- macOS：`~/Library/Application Support/BrandSentimentTrial`
- Windows：`%LOCALAPPDATA%\BrandSentimentTrial`

删除该目录会同时删除本机资料、导入数据、安装标识、许可证和运行记录。操作前请先在软件中导出需要保留的数据。

## 无需自建服务器

版本文件由 GitHub Releases 托管，不需要另行部署业务服务器。软件仅在用户主动操作时访问本项目固定的 GitHub Release 地址；业务数据不上传到 GitHub。
